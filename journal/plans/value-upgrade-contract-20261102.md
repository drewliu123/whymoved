# 投研助手 0.5.0：研究价值优先迭代

## 授权

2026-11-02，用户要求按前轮五项优先级改造迭代插件，并在实施依据选择中明确批准“批准本轮本地例外（推荐）”：允许本轮本地实现、测试、保存证据及更新本机插件，不向 GitHub 发布。这是本轮本地实施依据，不冒充 GitHub Issue。Owner / 验收者为当前用户。

## Problem / User Outcome

现有插件有严格证据、分析与模型，但交易研究没有统一保存市场押注、研究分歧、证据优势、催化及剩余机会；更新未逐项核对原触发，验证也主要检查工程链路。用户希望得到有方向、有增量、可用于发现值得交易机会的判断，而非防御性写作的绝对正确。

目标：以机会发现与判断更新为主线，让研究者承担判断和排序责任，同时保留证据与历史，不编造共识、精确收益或确定性。

## Scope / Non-goals

按优先级迭代主研究流程、取证与审查、报告双格式输出及更新对照；提供可版本化的机会研究记录，保留历史兼容。新增契约采用可选扩展，主流程要求价格相关的新研究使用；纯事实和非交易研究不被迫输出交易判断。旧报告无需迁移，新契约启用后字段不完整应失败。

不提供个性化仓位和账户指令，不接自动交易、后台采集、额外付费数据服务，不发布 GitHub，不追溯改写历史判断。不承诺预测准确率或投资收益。

## Acceptance Criteria

- AC-1：交易研究冻结市场押注及其依据类型（调查共识、价格隐含、研究代理估计）、研究分歧、证据优势、催化/时间、剩余空间与做错代价；缺精确数据可有据定性，不放松已有市场严格校验。自动验证引用、类型、缺字段和可选历史兼容。
- AC-2：研究与两类取证员按决策增量筛选，明确计算、连接、矛盾、判断更新；社区优先可核查领先线索。独立审查针对方向、幅度、时点与机会价值，不用免责声明数量代替质量。
- AC-3：机会结论采用 research_now / watch / priced_in / no_edge，并说明理由；Markdown/HTML 同源展示摘要与可追溯详情，不生成机械个人买卖指令。
- AC-4：每项触发有稳定 id、观察、时间/到期、支持/削弱/失效条件。更新逐项核对父报告全部触发，区分已触发/未触发/未检查，记录判断强弱、价格变化和剩余机会，拒绝错误父状态和遗漏触发，父档案不可覆盖。
- AC-5：冻结事前判断和后续观察用于前瞻复盘；案例覆盖方向判断与价格兑现分离、价格已反映、无优势、缺价格条件判断及非交易研究。工程测试与案例输出保存证据，样例不冒充真实收益评估。
- AC-6：运行项目实际 unittest 入口、插件验证、安装更新与缓存核对；保留源码基线及实际命令/退出码/日志。新会话加载要求如实说明。

## Risk / Rollback

medium：新增可选数据契约，主要影响启用机会研究的输入；通过负例测试、旧报告兼容和不可覆盖父记录控制。回退源码增量并重新安装原 0.4.1；保留新档案及导出，不删除研究数据。
