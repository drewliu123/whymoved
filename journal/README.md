# 研究档案与工作记录索引

本目录保存研究运行、旧预测账本、报告底稿及开发期案例。档案记录的是各自研究截点的判断，不能因仍在仓库中就视为当前有效或已重新联网验证。

## 代表入口

| 入口 | 用途与边界 |
|---|---|
| [runs/](runs/) | 按 run_id 保存的研究归档；读取每次运行的 manifest、报告、sources、claims、plan 与可选 audit，核对来源、时间和完整性。 |
| [黄金历史归档](runs/R20261104T071736Z-a21970468e9f/report.md) | 已保存的黄金研究示例；以该次报告、来源和审查记录为准，本索引没有重新取价或独立验证。 |
| [M20261031-03/](M20261031-03/) | 旧式 memo、预测、证据与审查材料；保留原 schema 与当时结论。 |
| [memos.jsonl](memos.jsonl)、[plans/](plans/) | 旧预测流程账本及计划；与新研究 run 归档区分阅读。 |
| [四类方法验证](four-type-validation-20261031/README.md) | 事件、资产、主题、机构行为的历史本地方法开发案例，含冻结材料、展示和检查；不是受控效果比较或预测优势证明。 |
| [NVDA 对比](nvda-compare-20261031/)、[NVDA 完整运行](nvda-full-runs-20261031/) | 当时的比较和运行材料，不应统称当前已联网验证的产品示例。 |
| [work/](work/) | 各主题原始抓取、选择前后来源、生成脚本、审查及中间产物；用于追溯过程，不是另一套产品实现。 |

## 工作痕迹与正式归档

`tmp-*` 文件及各批次 `work/` 是历史工作输入、中间结果或临时脚本。名称含 tmp 不代表可以直接删除：其中可能仍有研究来源或相对链接。`work/gold-20261104/` 等主题目录与正式 run 可相互补充，但工作稿不自动拥有正式归档的冻结、校验或独立审查资格。

新研究应创建新 run；更新旧研究应保留父 run，记录新增或修订证据、判断变化与可比口径。不得通过改写旧报告或旧账本来制造事后正确的历史。旧档案按原格式保留，不追溯补写当前 schema 或新结论。

[四类案例历史 ZIP](four-type-validation-20261031-delivery.zip) 保留原位；它是对应阶段的交付快照，当前使用请读[项目说明](../README.md)。未来重生成包宜作为带版本的 Release 附件发布，细则见[档案保留策略](../docs/archive-policy.md)。另见[验证证据](../evidence/README.md)、[研究资料](../research/README.md)与[交付索引](../delivery/README.md)。
