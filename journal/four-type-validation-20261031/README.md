# 四类投研案例验证

这是 v2 方案的本地方法开发验证，研究日期为2026-10-31。四个案例分别检验：事件规则与定价、单一资产变化、主题传导、机构条件性表态与行动。

打开 `index.html` 阅读统一成品，左侧切换案例，点击结论后的 `[C编号]` 展开证据。支持明暗模式、手机阅读与打印当前案例。HTML自包含，不需要服务器；外部来源链接需要联网。

每类目录保留：

- `report.json`：研究正文及呈现的共同数据。
- `report.md`：文字版。
- `claims.json`：事实、观点、推断及来源／依据。
- `sources.json` 与原始材料：可定位证据及获取失败记录。
- `calculations.json`：输入、计算与口径。
- `plan.json`：本例计划与范围。
- `validation.json`：研究执行者自检；不代替独立审查。
- `independent-review.md`：独立挑战及本轮处置。

`verification.json` 是最后一次字段、引用与现有校验器执行结果；`validation-summary.md` 是整体研究价值与方法缺口结论；浏览器检查另见 `browser-validation.json`。`work/` 为本轮本地生成／检查脚本，不属于插件产品实现。

本轮不修改插件，不写正式预测与作者账本，不发布外部平台。四例不构成受控效果比较、泛化测试或预测优势证明。NVDA复用已有冻结材料，其余案例记录各自实际研究截点，不能将异步报价视为同刻。
