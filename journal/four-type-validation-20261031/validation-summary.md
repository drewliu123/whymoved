# 四类代表案例验证结论

研究日期：2026-10-31。对象：v2改造方案的方法开发案例。执行方式：人工协调研究、既有证据规则校验、独立反方审查、本地同源HTML呈现。并未改造或验收插件自动执行链。

**四类方法都产出了具体的研究判断；四例也都留下了影响原问题完整回答的缺口。** 本轮没有受控旧版对照，因此“比旧版更有用”仍是基于案例的评价，尚未通过对照验证。 最值得保留的是：先回答用户问题，再指出哪个机制最有信息价值，用数字、竞争解释和下一观察支撑。字段校验全部通过并不意味着研究完成。

四例均为“部分满足”。这不是统一质量分数：事件缺独立概率，资产缺归因，主题缺增量利润归属，机构缺资本回报配对与治理资料，缺的是不同能力。

## 对方法的评价

事件方法的最大价值是防止把市场复制成自己的预测。本例可以把规则、官方驱动和可执行报价读清，但距离判断是否错价还有条件样本、概率模型和前瞻评分的距离。**能解释市场为何如此定价，与能证明市场定错，是两个验收目标。**

资产方法改善了近期表现与经营分析的连接。NVDA材料支持一个具体洞见：利润率方向必须与收入规模一起看。它也证明“找到一个有意思的财务问题”不能替代回答“为什么下跌”。以后变化归因任务必须先满足同期基准、事件时间线和预期变化输入。

主题方法把大叙事收敛到了可研究的价值捕获点。最重要的推进不是更大的用电预测，而是区分采购、积压、收入、分部利润、全公司净利和现金。并购比较范围及Corporate费用进一步说明：产品受益与股东经济回报之间仍有桥需要补。

机构方法在本轮最直接地产生了“原话—条件—实际行动—修订性质”的连续对照。它适合做长期跟踪，但不能用管理层原话代替独立因果核验，也不能从公开目标推断个人内心动机。

## 独立审查实际改变了什么

- NVDA：用直接披露GAAP毛利额72.142十亿美元替代舍入毛利率反推；修复证据副本路径与媒体更新时间性质；把现金回收降为核查线索，补板块共同因素竞争解释。
- 事件：默认条款的next scheduled meeting日期锚点也列为未明；单月实际消费放缓不外推持续需求收缩；保留两个成交价字段冲突，不把它解释为价格跳变；区分定性更新提示和可否定命题。
- 机构：把回报结论限制在本次六份电话会；归因标为管理层解释；补季度指引原话映射、正向ROI自述与明确金额/时限检验。
- 主题：补跨季并购口径和分部费用排除项；收窄订单到交付的因果措辞；按原金额统一利润率变化舍入；下半年展望用加权利润率验收。

逐例处置与未核实边界见各目录independent-review.md。独立审查仍以保存原文为主，不能证明外部响应真实性、历史访问盲法或未来结果。

## 改造取舍

建议保留公共证据与输出层、采用四类专属方法，并把“任务完成”与“证据规则通过”分开。四例作为开发样本，不作为产品已达标证明。

优先方法缺口是：事件补独立概率链与结算规则异常处理；资产补预期/基准/变化归因输入；主题补范围对账、价格/量/成本桥和利润归属；机构补原话版本、条件兑现、权限与回报数据。HTML样例已经能承载这些差异，继续扩大页面工程不应领先于研究能力。

本轮研究范围未覆盖Last30Days社区层的完整调用，不能据此评估社区增益。社区更适合发现叙事、竞争解释和调查线索；本轮最有用的发现主要来自官方原始数据、口径比较与独立审查。

未改插件、未写正式预测/作者账本、未发布GitHub。正式实现仍需主Issue、AI Ready与可机器验证的AC，并按工程规则另行授权。
