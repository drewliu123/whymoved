# 「更有投研意义」的可检验判据

一轮改动不因为「字段更多」或「文档更长」就算进步。每轮结束时，至少要有一项判据从「否」变「是」，或明显变强。

## 判据清单

1. **多一种分析师会用的方法**：相对估值、驱动式建模、财务质量、事件研究、情景分析、催化跟踪、行业传导——且方法有确定性计算或明确契约，不是再写一段提示词。
2. **多回答一类真实问题**：改完后能回答改之前答不了的问题（例：「现在的价格隐含多少倍 EBITDA」「这家公司的增长有没有现金流支撑」「下一个会改变判断的事件是哪天」）。
3. **多一条可核实的连接**：新输出能追到 claims/sources，或能由固定算术重算；不是模型自由发挥。
4. **边界更清楚**：新能力写明了什么时候不适用、样本不足/缺数据时输出什么、如何避免虚假精确。
5. **旧档案不被破坏**：历史 run 仍可 load/show/render；没有追溯改写。
6. **测试覆盖新路径**：正例、反例、边界、以及旧行为回归。

## 反模式（出现即视为本轮失败）

- 只加提示词、不加确定性能力，且没有新契约字段。
- 输出精确数字但无法重算，或依赖未记录的假设。
- 用更多免责声明代替更明确的判断。
- 为通过校验而伪造数据、用虚构示例冒充研究证据。
- 改动破坏旧归档兼容性，或让测试从「断言行为」退化为「断言输出字符串」。
- 一轮改动横跨过多文件，无法在一个 commit 内解释清楚。

## 评估方法

每轮在 log.md 中回答：

- 这轮让哪条判据前进？给出可复现证据（命令 + 结果）。
- 有没有引入新的「看起来很专业但实际不可核实」的东西？
- 下一轮最该补的缺口是什么？
