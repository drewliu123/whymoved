## 判断证据资格

真实取证应能定位到原始出处、获取时间、对象及期间，并核对当次状态与完整性；`partial`、失败或未运行不能提升为成功。保存下来的真实返回可用于离线复核，但复核旧快照不等于重新联网。

模拟回归 fixture 是人为构造或固定的输入、响应及预期值。即使字段形式与真实返回相同，也只能说明程序在给定条件下的表现。历史报告、实验和截图应保留原日期与声明，不用当前版本号替换旧结果。

本次索引整理未重跑这些历史请求，也未对旧研究结论作新的独立核实。完整报告见[研究档案](../journal/README.md)，原始资料与探索见[研究资料](../research/README.md)，保留与修订规则见[档案策略](../docs/archive-policy.md)。
