# 投研插件按需追赶世界模型：第一轮实验

## 结论

本轮未观察到显式依赖状态相对完整历史或等信息文字摘要的正确性增量。三组都通过18项预设检查。对“隔很久再问降息”的短材料场景，普通Agent拿到可靠旧记录和新证据，已经能完成状态重建与有选择的判断修正。

因此当前不建议以重型世界模型重构插件。优先建设轻量、持久、带时间与来源的研究状态，以及提问时的时效核验和按需补查。跨会话保存的产品价值是合理设计假设；本轮没有设置无记忆/从头联网对照，未实测这一价值或检索节省。图结构、自动传播、主动工具选择须另验证，不能从本轮外推。

## 实验做了什么

日期：2026-11-02。

- 两个任务、三种表示、六次独立新子Agent运行，未指定不同模型，未锁定后端配置。
- history：逐条完整历史和自然语言依赖；summary：相同条目与依赖的连续文字；state：相同条目加显式依赖边。
- 所有组拿到相同新证据、相同任务和JSON输出契约。没有刻意削弱基线。
- 事前冻结输入、评分表及SHA256；独立评审只读匿名输出与评分协议，不读条件映射。
- 真实事件为2024年7月31日到11月8日的政策更新，旧判断为实验编写；另用完全虚构的央行案例减轻历史知识泄漏。

## 结果

| 表示 | 真实事件检查 | 虚构修订检查 | 总计 | 两任务输入UTF8字节 |
|---|---:|---:|---:|---:|
| 完整历史 | 8/8 | 10/10 | 18/18 | 10,253 |
| 文字摘要 | 8/8 | 10/10 | 18/18 | 10,223 |
| 显式依赖状态 | 8/8 | 10/10 | 18/18 | 11,672 |

所有组均能：确认当前政策状态、结束过期研究目标、保留历史初值与当前修订值、修正受影响判断但保留条件机制、保留无关条目、拒绝用异步成交认定套利、提出相关后续检验。

显式状态输入较文字摘要长约14.2%，但这里只是UTF8体积，不能当作token或真实成本。未采集调用计费、模型推理token和可比运行时延，也未计状态生成维护成本。

完整历史组虚构例有一个附加表述问题：将套利所需初始净收入严格为正写成必要条件，遗漏常规定义下的零成本套利情形。盲评单独记录，未修改预先评分；每格一次，不能归因为表示差异。原始输出保留，不事后修改试验结果。

## 如何理解

这轮最重要的发现是强基线也能完成更新。此前关于“依赖变化需要显式世界模型才做得好”的直觉，至少在这两个简单案例上没有获得支持。

任务证据已经人工筛选；历史依赖也人工给定。测试的是表示层与局部状态更新，不是开放研究、历史补查或agentic工具规划。所谓长间隔只是任务日期变化，没有真实长期自主维护过程。两例、每格一次且出现满分天花板，既不能证明普遍无效，也不能宣称研究能力提升。

独立设计审查还指出：评分与人工条目高度对应；显式边可能只是令已有答案线索更易读取。真正需要检验的是预算受限时，能否更好找到关键证据，并据此改善结论，而非是否更整齐地填完更新字段。

## 对插件的建议

先做最小持久研究状态：当前问题与截止日期、已核实事实及版本、判断及依据、竞争解释、下一观察、上次核验时间。由宿主Agent在用户再次提问时读取、检查时效并补查；旧快照不覆盖。暂不为图数据库和通用传播框架投入大规模开发。

后续有区分力的实验应比较强摘要与轻量结构状态，在相同预算下，从未经筛选的材料目录中自行选择查询；覆盖多事件共享证据、多跳依赖、错误或缺失依赖边、无关噪声、情景转换和应保留的旧判断。冻结同一模型设置、做配对重复，分别测研究结论、遗漏/误改、材料选择价值及真实成本。只有研究收益或成本优势稳定出现，再扩展world model。

## 文件与复现

- protocol.md：运行前声明的设计和评分规则。
- build_experiment.py：生成六个输入及ground truth；仅重建输入，不重跑模型。
- manifest.json：输入清单、SHA256及体积。
- *-input.json / *-output.json：六次输入与原始输出。
- prepare_blind_review.py：核验输入哈希、输出字段、旧条目覆盖和状态，产生匿名包。
- blind-outputs.json / blind-key.json：匿名评审包与揭盲映射。
- review.json：独立盲评逐项理由与附加问题。
- summarize_results.py / results.json：核对评分并汇总。
- artifact-checks.json：结构核验及字节记录。

输入生成和汇总可用Python3标准库重跑。模型运行由六个独立子Agent完成，调用提示为仅读指定输入并按其中instructions写output_path；并非可离线确定性复现的模型结果。未修改插件生产代码或已安装插件。
