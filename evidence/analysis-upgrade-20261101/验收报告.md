# 投研插件 0.4.0 升级验收

四处分析能力已完成，已更新本机 `touyan@touyan-local` 至 **0.4.0**。源码和安装副本均通过 **151 项自动测试**。新建会话后会加载新版研究流程；当前会话没有验证热重载。

## 四处升级的实际变化

| 升级点 | 研究时的行为 | 已实现的约束与验证 |
|---|---|---|
| 问题匹配方法 | 先明确研究主问题、基准和经济传导链，再选择方法 | 六条明确路由：变化归因、经营展望、估值、事件预测、主题传导、承诺兑现。计划与报告的方法必须一致；这是研究者选择后的路由校验。 |
| 寻找能区分解释的证据 | 先写不同解释各自预测什么，再按检验取证 | 检索关联检验；报告保留事前预测；观察至少引用事实、价格或共识证据。缺证据必须标明缺口，不能支持或削弱解释。 |
| 机制进入可复算模型 | 收入与利润、现金需求、企业价值和价格隐含增长进入确定性计算 | 经营利润桥、简化 FCFF、DCF、反向 DCF 四种模型；区分观察与假设，引用输入主张，记录单位和口径，重算输出及单参数敏感性。亏损与扭亏使用金额变化，避免负利润基数的增长率误导。 |
| 连接市场预期 | 价格相关问题对比市场隐含要求、研究情景、差距及改变判断的条件 | 估值关联反向 DCF；价格值、每股币种和标的与报价证据一致。无法识别隐含预期时明确披露缺口；经营或人物研究可说明价格分析不适用。 |

正文继续先给判断、机制与关键结果；预测矩阵、模型参数、敏感性和证据引用放附录。Markdown 与 HTML 来自同一报告输入。

## 独立审查

首次独立审查复现五项问题，均已修复：

1. 新模型 id 可供计算型发现和主张引用，并拒绝与旧计算 id 重名。
2. 币种、缩放和标的变化纳入更新可比性检查。
3. 经营桥支持亏损、扭亏及正基数转亏；零或负利润基数省略增长率。
4. 独立报告不能裁定本检验未涉及的假设。
5. 独立报告不能把相同解释换编号冒充竞争解释。

独立复核逐项确认关闭，并另行执行分析模块 46 项测试，退出码 0。记录见 [review.json](review.json)。完整 151 项测试的日志见 [tests.stderr.log](tests.stderr.log) 和 [installed-tests.stderr.log](installed-tests.stderr.log)。

## 已验证范围与使用边界

本次验证了字段契约、证据引用、固定模型算术、归档安全与兼容性。经济解释、假设合理性和因果判断仍由研究者提出，并接受 red-team 审查；未进行实时联网研究或预测准确率、投资收益评估。DCF 使用企业自由现金流 FCFF 与 WACC；负现金流估值需要其他适用方法，当前模型会明确拒绝。

插件清单校验通过，但目录检查仍有原有的非阻塞警告：缺图标、根目录及 skills 目录的 `.DS_Store`。本次没有进行公开目录发布。没有独立 build/lint/typecheck 流程的通过记录；本插件的已发现验证入口为 Python 标准库 unittest 和插件校验 CLI。

新 archive/update 强制分析契约；历史档案无需补写新字段即可读取。更新旧研究时生成新档案，保持原档案不可覆盖。
