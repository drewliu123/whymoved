## 离线内容演练

材料：cases.json，包含市场变化解释、经营展望两个虚构案例。演练只读新增背景参考、预期参考和材料，不联网，不执行归档或模型程序。实际结果见offline-results.md，未经编辑的原始产出另存offline-results-original.md。

主研究者逐项人工核对结果：

| 检查 | 市场变化解释 | 经营展望 |
|---|---|---|
| 相关长期条件与近期变化 | 区分资本投入依赖、此前能源压力及本周状态 | 区分长期需求、交付周期、产能和近期成本 |
| 匹配事前预期 | 使用最新100而非旧96比较实际98；没有把现金流恶化称为意外 | 分开公司100—105指引与调查108；识别指引未下调 |
| 背景不能替代新增时点 | 不把原有能源压力当本周新增冲击；保留宏观重估竞争解释 | 不把95%利用率称为新恶化，不把次年产线计入Q4 |
| 传导与竞争检验 | 比较财报后弱势与此前普跌，未给确定跌幅贡献 | 比较按批次验收与成本/调价错位，未把订单当收入 |
| 无关背景取舍 | 未把缺乏联系的乙国选举列为原因 | 未把无关互联网监管列为原因 |
| 数字与假设 | 收益差−2.9个百分点，现金流差额−4十亿；未把机械权重示意称实际贡献 | 营业利润情景+3%或−7.3%；明确假设与环比，未虚构同比 |
| 正文精简 | 原始257字符（含引用），没有五层栏目 | 原始269字符（含引用），没有五层栏目 |

发现并修正两处表达问题：市场正文原句“不能称新增宏观恶化”范围过宽，收窄为“未见能源或利率新增上冲证据”；现金流差额补明“经营”及十亿单位。样例没有提供收入币种和金额单位，未补造。修订属于主研究者编辑，原始输出保留供复核。

两例满足本轮给定材料下的内容检查，不代表已验证自主联网发现背景或完整Skill端到端运行。没有执行固定模型CLI，演练中的算式不标成模型验证通过。
