微软 FY2026：利润有现金支撑，capex 强度升到 34.9%

微软 FY2025 的利润增长有现金支撑吗？

研究截点 2026-11-14T00:00:00Z · asset · 盈利质量筛查

执行摘要

结论：FY2026 CFO 182,935 是净利润 133,749 的 1.37 倍；capex 115,948 是折旧 34,300 的 3.38 倍，投入远高于维护。

最反直觉：利润质量没有恶化，但 capex/收入从 22.9% 升到 34.9%；利润的现金支撑越强，投资强度也越高。

接下来验证：看 FY2027 capex 增速能否低于收入增速；若 capex/收入维持 35%，折旧会开始追上利润。

判断

FY2026 经营现金流 182,935 是净利润 133,749 的 1.37 倍，利润有现金支撑；资本开支 115,948 是折旧 34,300 的 3.38 倍，投入偏扩张。capex/收入从 22.9% 升到 34.9%，增量利润率约 53%。结论：利润质量不是问题，投资强度才是；FY2027 看 capex 能否见顶。[C19] [C20] [C21] [C22] [C23]

利润有现金支撑：CFO/净利润 1.37

FY2026 CFO 182.935、净利润 133.749 十亿美元；CFO/净利润从 FY2024 的 1.34 升到 1.37。[C5] [C4] [C13] [C12] [C21] [C20]

为什么重要：现金转化没有恶化；利润不是会计数字。

capex 是折旧的 3.38 倍

FY2026 capex 115.948 vs 折旧 34.300 十亿美元；capex/D&A 从 1.89 升到 3.38。[C14] [C15] [C22] [C23]

为什么重要：投入远超维护需求，指向 AI/产能扩张；若收入兑现是护城河，否则是折旧压力。

capex 强度升到收入 34.9%

capex/收入 18.1%（FY2024）→22.9%（FY2025）→34.9%（FY2026）。[C1] [C6] [C9] [C14] [C17] [C22]

为什么重要：投资强度是 FCF 与未来折旧的核心变量；34.9% 已高于多数云同行。

增量利润率约 53%

营业利润增量 26,709 / 收入增量 50,115 = 53.3%；营业利润率 46.8%。[C9] [C11] [C17] [C19]

为什么重要：收入增长仍在带来高增量利润；这是 capex 扩张的底气。

这意味着什么

利润质量不是问题，投资强度是

CFO/净利润 1.37；真正要跟踪的是 capex/收入 34.9% 能否回落。（FY2027）[C21] [C20] [C22] [C17]

capex/收入是关键指标

从 18.1% 升到 34.9%；回到 30% 以下，FCF 与折旧压力才会缓解。（FY2027）[C6] [C22] [C17]

增量利润率支撑扩张

增量利润率 53.3%，收入增长仍在创造利润；扩张不是无回报投入。（FY2027）[C11] [C19] [C9] [C17]

情景与触发条件

capex 见顶

FY2027 capex 增速低于收入，capex/收入回落。

触发：capex 增速 < 收入增速；capex/收入 <30%；CFO/净利润 >1.2

含义：投资强度缓解。

投资维持

capex/收入维持 35%，折旧开始追上利润。

触发：capex/收入 >35%；折旧增速 >收入增速；营业利润率下降

含义：折旧压力上升。

收入加速

收入增速超过 capex，强度被动下降。

触发：收入增速 >20%；capex 增速 <15%；增量利润率 >50%

含义：扩张被收入消化。

分析判断

FY2025 利润增长有现金支撑，投入偏扩张；资本开支强度是后续要跟踪的变量。[I-JUDGE]

传导关系：收入 → 营业利润 → 净利润 → 经营现金流 → 资本开支

模型不适用：本轮用确定性报表筛查，不适用固定估值模型
