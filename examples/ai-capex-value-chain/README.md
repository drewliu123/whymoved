# AI 资本开支的价值，主要不在出钱的人手里

问题：**AI 资本开支的价值落在链条的哪一环？**

用四组真实数据横向比较（SEC XBRL，FY2024→FY2025；英伟达为 FY2025→FY2026）：

| 环节 | 代表 | 收入增速 | 现金流变化 |
| --- | --- | --- | --- |
| 资本开支 | 三家云厂商合计 | **+59.9%** | — |
| 云收入 | 微软 / Alphabet / 亚马逊 | +14.9% / +15.1% / +12.4% | FCF 利润率 −2.7 / −4.4 / −4.5 个百分点 |
| 设备 | AMAT / LRCX / KLAC | +4.4% / +23.7% / +23.9% | — |
| 算力 | 英伟达 | **+65.5%** | CFO/净利润 0.86 |

**结论：增量主要落在算力供应商，其次是部分设备商；出钱的云厂商收入增速最低、现金流承压。** 云厂商营业利润率仍在上升，FCF 利润率却下降——资本开支不经过营业利润，压的是现金流。算力供应商收入增长最快，但英伟达 CFO/净利润 0.86、应收天数 65，现金质量也在打折。

**受益顺序：算力 > 部分设备 > 云厂商现金流。** 这不是「AI 利好一切」；选 AI 暴露先看你在链条的哪一环。

**但价格把顺序反过来了一部分。** 2026-11-13 收盘的 trailing P/E：

| 公司 | 环节 | P/E | 收入增速 |
| --- | --- | --- | --- |
| AMAT | 设备 | **42.8x** | +4.4% |
| KLAC | 设备 | 41.6x | +23.9% |
| LRCX | 设备 | 39.2x | +23.7% |
| 英伟达 | 算力 | 33.2x | +65.5% |
| 亚马逊 | 云 | 37.2x | +12.4% |
| 微软 | 云 | 29.2x | +14.9% |
| Alphabet | 云 | 27.4x | +15.1% |

设备商最贵（39–43x），算力 33x，云 27–37x。**估值顺序：设备 > 算力 > 部分云；价值顺序：算力 > 部分设备 > 云。** AMAT 增长 4.4% 却对应 42.8x，是价值链里最脆弱的组合。

## 三种情景与触发条件

| 情景 | 触发 | 含义 |
| --- | --- | --- |
| capex 维持 | capex 增速 >30%、英伟达收入 >40%、云 FCF 不再下降 | 价值链格局维持 |
| capex 回落 | capex 增速 <0、云 FCF 回升 2pp 以上、设备收入转负 | 受益顺序反转 |
| 变现加速 | 云收入 >25%、capex <10%、云 FCF 企稳 | 云厂商重新占优 |
| 设备估值下修 | 设备收入 <10%、设备 P/E 仍 >35、英伟达收入 >40% | 估值风险从算力转向设备 |

情景不给概率，只给「看到什么就相信什么」。

## 这个示例演示什么

- **价值链比较**：同一资本开支周期里，四个环节的收入与现金流放在一张表。
- **反直觉结论**：capex 增 60%、云收入只增 12%–15%；利润表与现金流背离。
- **环节分化**：设备商 4.4%–23.9% 的差距，比行业平均更有信息量。
- **不吹赢家**：算力增长最快，但现金转化也在下降。

## 边界

- 英伟达用 FY2026（2026 年 1 月）与云厂商 FY2025（2025 年 12 月/6 月）比较，存在约半年到一年期间错位。
- 只有收入、利润率与现金流，没有分部收入与订单；不能判断各环节的长期份额。
- 没有估值，不回答「当前价格是否已反映」。
