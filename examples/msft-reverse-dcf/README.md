# 反向 DCF 示例：微软现价隐含多少自由现金流增长？

这是第一个基于**真实现金流、真实现价与显式假设**的反向 DCF 示例。问题：**当前价格隐含了多少自由现金流增长？**

数据与假设：

- 自由现金流：FY2026 经营现金流 182,935 − 现金资本开支 115,948 = **66,987** 百万美元（SEC 10-K）；
- 净债务：有息负债 40,294 − 现金及等价物 20,935 = **19,359** 百万美元（不含短期投资）；
- 股数：7,453 百万；现价：**523.88** 美元/股（Nasdaq 2026-11-13 收盘）；
- 假设：折现率 **8%**、终值增长 **2.5%**、显式期 **5 年**——都是研究者的假设，不是市场共识。

| 假设 | 隐含五年 FCF 增速 |
| --- | --- |
| 恒定增长，8% 折现 / 2.5% 终值（基准） | **31.2%** |
| 恒定增长，7% / 9% 折现 | 25.4% / 36.3% |
| 恒定增长，终值 2.0% / 3.0% | 33.3% / 28.9% |
| **显式期后 5 年线性收敛**，8% / 2.5% | **23.0%**（敏感性 18.9%–26.6%） |

阶段结构本身是假设：同一现价下，加入 5 年线性收敛后隐含增速从 31.2% 降到 23.0%。

同期按同一口径的自由现金流：

| 财年 | 经营现金流 | 现金资本开支 | 自由现金流 |
| --- | --- | --- | --- |
| FY2024 | 118,548 | 44,477 | 74,071 |
| FY2025 | 136,162 | 64,551 | 71,611 |
| FY2026 | 182,935 | 115,948 | **66,987** |

**结论：现价隐含约 31%（恒定）或 23%（5 年收敛）的五年自由现金流增速，而过去三年自由现金流在下降。** 价格要么依赖资本开支回落后现金流重新加速，要么依赖更低的折现率/更高的终值假设。这是研究要解释的差距，不是「贵/便宜」的标签；本示例不构成买卖建议。

## 这个示例演示什么

- **反向 DCF 的完整输入**：FCF、净债务、股数、现价全部可回溯；折现率、终值、年限与求解区间都是显式假设。
- **假设敏感性**：折现率与终值各做两端扫描，隐含增长从约 25% 到约 36%；加入 5 年线性收敛后整体降到 18.9%–26.6%。
- **阶段结构对照**：同一价格、同一组输入，恒定增长与多阶段收敛并列展示，避免把单一阶段的结果当成唯一答案。
- **历史对照**：同口径 FCF 轨迹（74,071 → 71,611 → 66,987）与隐含增长方向相反，差距被写进判断与发现。
- **口径声明**：FCF = CFO − 现金资本开支；净债务不含短期投资；两者都写进限制。

## 边界

- 折现率、终值与显式期都是假设；换假设会显著改变隐含增长。
- FCF 口径为 CFO − 现金资本开支，不含融资租赁等其他调整；净债务不含 559 亿美元短期投资。
- 反向 DCF 是算术反推，不回答「市场为什么这样定价」，也不构成目标价或买卖建议。
