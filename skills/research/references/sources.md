# 来源资格与阅读顺序

层级回答“这段材料能支持哪类主张”，阅读顺序回答“现在先读什么”。两者分别判断。官方首页可能不回答问题，一条低热度社区线索可能值得先核查。

| 层级 | 来源职责 | 支持范围 |
|---|---|---|
| T0 | 监管/统计原始文件、公司原始披露、正式规则、交易所/订单簿 | 对应事实；明确选项和时刻的报价。管理层归因仍是自述 |
| T1 | 有样本和方法的调查、预期数据、隐含定价 | 调查覆盖人群的预期；指定模型/合约价格。不能自动等同全市场共识 |
| T2 | 独立媒体原始采访、调查与报道 | 两个已确认独立原始出处可支持事实；单篇可提供待核查线索与归属明确的观点 |
| T3 | 机构、行业专家、研究者的分析与模型 | 解释、假设、反例和预测；其中引用的事实数字追溯T0–T2。可记录“该机构说了什么”，不升级其观点为客观事实 |
| T4 | 社区帖子/评论/视频/公开讨论 | 谁在说什么、条件分歧和调查线索；样本内观察，不能外推全市场或支持外部事实 |

分层以片段及用途为单位。公司官方账号的正式公告可追溯T0，普通评论仍是观点。域名、认证、粉丝量、历史命中率都不能代替原文支持。

## T1预期取证

涉及预期差、事件概率、财报共识或预期修订时，读取[expectations.md](expectations.md)。按问题补调查数值、市场隐含定价及同目标期间的历史变化；调查、模型、公司指引和社区叙事分别处理。媒体承载的具名调查须追溯原始提供方，资格仍按evidence.md，不因转载数量升级。官方调查的收集日不等于公开日，缺少事前可得性证据不得用于历史判断。

## 阅读和选择

先排除对象不匹配、越过截点和仅有摘要却被当作原文的材料，再按研究用途判断：

1. 是否直接回答问题，能否区分候选解释。
2. 是否提供原始数字、规则、方法或可定位细节；是否有新信息。
3. 时间、地区、对象、单位与当前比较是否匹配。
4. 是否补充独立原始出处、重要反证或未覆盖观点。
5. 同等相关材料内保留引擎原排名和同平台互动信号。

这些是研究者给理由的选择维度，不是未经评估的加权总分。`selection`记录relevance、purpose、priority与reason；脚本执行确定性排序/选择审计。原候选和未入选原因保留。互动缺失不等于低质量，跨平台点赞不作直接比较。Last30Days的relevance_score可能是混合总分，保留原名与上下文，不当作纯语义相关性。

URL规范化去重与原始出处家族去重分别处理。五家媒体转载同一公告只算一个origin；同publisher的不同文件也不自动算独立。`origin_id`需要原始出处与`origin_basis`，未知就留空，不为过校验编造独立性。同一话题的不同解释保留，聚类不能抹掉分歧。营销/协调传播只记可核实迹象，不凭账号相似认定机器人。

## 分工与来源入口

fact-collector覆盖T0–T3：官方实际、预期/调查、媒体独立核查、机构机制/反例。community-scout覆盖T4及其线索追溯。主研究者合并、选择与综合。

| 研究对象 | 优先入口示例 |
|---|---|
| 宏观事件 | BLS、BEA、Fed日历/声明/讲话、FRED原始系列；CME方法与报价、经济学家调查；Reuters等报道；机构研究；相关社区 |
| 预测市场 | 精确市场规则、Gamma身份/参考值、CLOB订单簿、Kalshi合约；裁决源；同事件其他市场与社区争议 |
| 美股 | SEC、公司IR/财报/电话会；交易所/可靠报价；同期指数和行业；预期来源方法；机构与相关社区 |
| 加密资产 | 项目原始公告、链上数据/方法、交易所合约；资金费率/期权；研究机构与开发者/用户讨论 |
| A股/港股 | 巨潮、上深交易所、披露易、统计局/央行；财新/第一财经等；券商研究与雪球等讨论 |
| 主题/机构 | 客户采购与项目、竞争者原始资料、行业方法文件、承诺历史版本；不要只读被研究方自己的解释 |

每条查询保存query、source、executed_at、结果状态和候选路径。状态契约为ok、partial、no_results、not_run、error、rate_limited、auth_failed、payment_required、unreachable、timeout、schema_drift；获取失败用error/具体失败状态，无结果用no_results，不兼容用schema_drift；不得把未执行或平台失败写成没有讨论。搜索结果只提供线索，重要结论打开原文，记录quote、locator和retrieved_at。历史截点需要当时可得性证据；今天可访问不能证明过去可访问。

## 结构化金融数据

股票财务与当前行情快照可按[金融接口参考](financial-data.md)调用`scripts/financial_data.py`。这是按Dexter公开契约接入Financial Datasets的可选获取工具，依赖供应商授权；未配置不请求，公开探测需显式指定。保留原始响应、来源与状态，不能把API获取成功等同T0资格或历史可得性，也不能把partial当完整结果。合并候选前按evidence契约补齐原文与口径。

## Last30Days边界

继续调用已安装引擎，不复制其认证、抓取、聚类和重排实现。使用`--research-only --emit=json --json-profile=raw`，保留items_by_source、ranked_candidates、clusters、完整source_status。它们是引擎暴露的候选池，不是平台完整召回。适配器导入后仍需补原文与研究选择，不能把标题当支持结论的原句。

诊断可用来源再计划；Python3.12+运行引擎，插件自身Python3.9+。`--save-dir`只控制部分输出，仍可能写引擎last-run/cache；TOUYAN_HOME不隔离该缓存。记录引擎版本、命令、状态与输出路径；不声称零写入。

## 作者记忆（可选）

旧authors.py评分规则保持：复盘≥3且命中率≥60%为core，≤30%为demoted，其余watch。它衡量已登记样本中的命中率，不是事实可靠性评分，也没有“watch观点权重减半”的执行机制。

只有用户要求使用作者记忆时读取/定向；新作者先放本轮候选，不因命中≥2条就自动写正式库。候选说明样本范围与选择理由。研究归档不修改作者库，显式预测复盘仍可能根据作者立场评分，应在执行前说明写入影响。
