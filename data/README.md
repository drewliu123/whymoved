# 数据与本机运行状态索引

本目录同时涉及旧业务账本与本机 SEC 运行状态，两者保留方式不同。原始研究证据并不集中在这里，还分布在[research/](../research/README.md)、[evidence/](../evidence/README.md)及[journal/](../journal/README.md)。

## 内容分类

| 路径 | 用途与保留方式 |
|---|---|
| [authors.json](authors.json) | 旧作者/预测评分流程的数据账本；属于历史业务记录，应保留原格式和历史，不因清理缓存而一并删除或重置。 |
| `sec-cache/` | 本机 SEC 获取缓存，可包含下载文件和解析中间产物；不是完整、永久或经过研究选择的证据档案。仓库整理将其作为本地运行缓存取消跟踪，本机文件保留；新克隆不应依赖它存在。 |
| `sec-runtime.json` | 本机独立 Python 与 EdgarTools 依赖路径配置，不是可移植安装清单或研究结论。仓库整理将其作为本机配置取消跟踪，本机文件保留；其他机器按安装说明自行配置。 |

`sec-cache/` 和 `sec-runtime.json` 是本地可选路径，因此这里不将它们设置为新克隆必须存在的链接。取消 Git 跟踪不等于删除本机文件，也不等于删除已归档的 SEC 取证快照。缓存文件若支撑某条研究主张，应把必要的原始返回、出处、时间、定位及完整性状态另存进相应研究运行，再建立来源/主张链；不能只依赖缓存路径。

`EDGAR_IDENTITY` 等身份配置按[SEC 数据参考](../skills/research/references/sec-data.md)从进程环境提供；不在数据索引或历史包中新增个人身份或凭据。数据根位置、安装与运行时配置以[项目说明](../README.md)为准。研究档案、原始材料、临时工作痕迹与缓存的具体边界见[档案保留策略](../docs/archive-policy.md)。
