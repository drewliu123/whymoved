# 研究资料索引

这里保存方法调研、第三方资料、案例取证与实验记录。它们是插件设计和研究过程的历史依据，不是当前行情或已重新联网验证的研究结论。每份材料的日期、来源、冻结截点和限制以其原始记录为准；本索引不重判旧结论。

## 与其他目录的关系

生产流程与实现位于 [skills/](../skills/)、[agents/](../agents/)、[scripts/](../scripts/)；自动测试位于 [tests/](../tests/)。本目录的探索脚本、缓存和本地评估环境不应被当作额外安装入口。`edgartools-eval-venv/` 属于本机评估环境，不是研究证据或可移植依赖包。

阅读研究成品及完整运行链请从[研究档案](../journal/README.md)进入；验证材料从[证据索引](../evidence/README.md)进入。历史文件与相对路径保留，后续新增版本和修订应遵循[档案保留策略](../docs/archive-policy.md)。
