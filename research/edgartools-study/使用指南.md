## 最合适的初次使用：本地 MCP

MCP 将财报能力直接提供给现有 Agent，不需要用户每次写 Python。官方入口是 `python -m edgar.ai` 或 `edgartools-mcp`。

以下配置使用本次已经安装的隔离环境，而非每次临时解析最新版。把身份占位文本换成自己的真实姓名和联系邮箱；这不是账号密码，也不需要发到聊天里。此研究没有替用户填写身份或修改客户端配置。

Claude Code：在投研助手项目目录执行下面命令。`--scope local` 表示只对当前项目注册到个人配置，避免把个人联系信息写进可共享的项目配置。

```bash
claude mcp add --scope local --transport stdio edgartools \
  --env 'EDGAR_IDENTITY=你的姓名 你的联系邮箱' \
  -- '/Users/frankzhang/.local/bin/python3.12' '/Users/frankzhang/Desktop/投研助手/research/edgartools-study/run_mcp.py'
```

然后重新开启 Claude Code 会话，用 `/mcp` 查看连接状态。此命令按当前本机 `claude mcp add --help` 的参数契约核对，尚未执行注册。

其他 MCP 客户端可将下面的服务项合并到自己的 MCP 配置。不要用整段覆盖已有客户端配置。

```json
{
  "mcpServers": {
    "edgartools": {
      "command": "/Users/frankzhang/.local/bin/python3.12",
      "args": ["/Users/frankzhang/Desktop/投研助手/research/edgartools-study/run_mcp.py"],
      "env": {
        "EDGAR_IDENTITY": "你的姓名 你的联系邮箱"
      }
    }
  }
}
```

不使用本地环境时，官方还支持 `uvx --from 'edgartools[ai]' edgartools-mcp`，但要自行确保 Python >=3.11，并最好锁定经过验证的版本。本次没有修改全局 Python、安装全局技能或接通托管平台。

## 给 Agent 的实际提问

接通 MCP 后，可以直接用现有投研助手入口，例如：

```text
/touyan:research 用 EdgarTools 找到 NVDA 最新一份已披露的 10-Q。
分析收入增长有没有转化成现金流，重点核对应收账款、库存和现金流。
列出报告期、披露日期、accession number 和 SEC 原始出处。
涉及长章节时不要把 MCP 的截断片段当作全文。
```

其他适合的提问：

- “读取微软最近两份年报的风险因素与管理层讨论，找新增的重要变化；先定位具体公告，再比较原文，区分新增措辞与风险已经发生。”
- “比较 AMD 和 NVDA 最近几个季度的收入增长、毛利与经营现金流；统一财季、币种、单位和单季/累计口径。”
- “找到苹果最新财报相关的 8-K，核对 EX-99.1 业绩新闻稿及指引，区分公司指引与外部机构预期。”
- “查看某公司最近的 Form 4 内部人交易，区分交易类型；不要把所有转让或税款代扣都写成主动卖出。”

这些是建议的使用请求，不是本次已经执行并获得真实财报数据的案例。

## 常用工具与调用顺序

本地 MCP 源码注册以下 13 个工具：

| 工具 | 适合的任务 |
|---|---|
| `edgar_company` | 公司概况、财务报表、最近公告；可选 annual/quarterly/ttm |
| `edgar_search` | 找公司或按类型找公告 |
| `edgar_screen` | 按行业、交易所等筛选公司 |
| `edgar_text_search` | 在 SEC 披露正文中搜索关键词 |
| `edgar_filing` | 用公司+类型定位最新披露，或用 accession 精确定位文件 |
| `edgar_read` | 读取 MD&A、风险因素、业务、8-K 新闻稿等指定章节 |
| `edgar_notes` | 深入收入确认、债务、租赁等财务附注 |
| `edgar_trends` | 财务序列及增长率 |
| `edgar_compare` | 多公司财务比较 |
| `edgar_ownership` | 内部人交易、机构组合 |
| `edgar_monitor` | 查询当前 SEC 披露 feed；不是后台自动监控任务 |
| `edgar_fund` | 基金相关披露 |
| `edgar_proxy` | 薪酬与公司治理 |

公司研究常见链路：`edgar_company` → `edgar_filing` 确认文件 → `edgar_read` / `edgar_notes` 阅读 → `edgar_trends` / `edgar_compare` 对照。

正式写证据时，应先锁定 accession，后续围绕同一文件读取，避免多个“latest”调用选到不同披露。历史研究应先按当时公开时间选文件，不能用最新 CompanyFacts 替代历史快照。

## Skill、MCP、Python 怎样选择

- **MCP**：给 Agent 直接提供一组可调用工具，适合先体验和研究探索。

## Python 基础示例

以下为根据本次源码与官方示例核对的使用方式；联网执行需先设置自己的 `EDGAR_IDENTITY`。本次不替用户伪造 SEC 联系身份。

```bash
export EDGAR_IDENTITY='你的姓名 你的联系邮箱'
'/Users/frankzhang/.local/bin/python3.12' - <<'PY'
import os
import sys
sys.path.insert(0, '/Users/frankzhang/Desktop/投研助手/research/edgartools-eval-venv/lib/python3.12/site-packages')
os.environ['EDGAR_LOCAL_DATA_DIR'] = '/Users/frankzhang/Desktop/投研助手/research/edgartools-study/data'
os.environ['EDGAR_CACHE_DIR'] = '/Users/frankzhang/Desktop/投研助手/research/edgartools-study/cache'
from edgar import Company, set_identity

set_identity(os.environ['EDGAR_IDENTITY'])
company = Company('NVDA')
filings = company.get_filings(form='10-K', amendments=False)
if filings is None or len(filings) == 0:
    raise RuntimeError('未找到原始 10-K')
filing = filings[0]
print('公司:', company.name)
print('披露日期:', filing.filing_date)
print('文件编号:', filing.accession_no)
print('SEC URL:', filing.url)
report = filing.obj()
print(report.management_discussion)
# 如需整个主文件正文：filing.text()；Markdown：filing.markdown()
# 如需公司级多期表：company.income_statement(periods=4)
PY
```

主文件全文不等于所有附件全文，业绩新闻稿可能在 EX-99.1 等附件里，必须确认实际使用的文件。

## 对投研助手最重要的源码发现

### MCP 返回的片段可能被截断

`edgar/ai/mcp/tools/reader.py` 的普通章节输出上限为 6000 字符，包含 `full_text` 路径；回退正文预览为 4000 字符。`base.py` 会附加 `... (truncated)`。13F holdings 是按行数另行处理的例外。

因此，`sections=['all']` 或 `['full_text']` 不等于拿到了整份文件。需要完整核对披露时，应使用 Python 的 `filing.text()` / `filing.markdown()` 或具体章节，保存完整正文，再分块取证。

### 公司财务结果适合阅读，但不宜直接作为模型输入契约

`company.py` 优先通过 `to_llm_string()` 格式化财务表。`edgar_filing` 的 context 也是用于 Agent 阅读的上下文。要接入我们已有模型，应从 Python 数据对象提取数值、单位、期间、concept、原始 accession 与衍生计算标识。

### 最新报表不等于历史当时可用的数据

需要区分报告期、申报日期、接受/公开时刻、修订及重述版本。`edgar_filing(identifier=..., form=...)` 默认取最新，做历史问题时应改为精确 accession 并核对公开时刻。日粒度 `filed` 不足以自动证明同一天某个时刻已经公开。

### 免费本地 MCP 与托管 MCP 是不同产品

本次研究的是开源库和本地进程。`app.edgar.tools` 的托管 MCP 有额外增强、登录和套餐，不能把两者的功能与免费范围混用。

## 建议怎样接到我们的插件

先用本地 MCP 体验，再增加一个独立 Python 适配器作为正式取证入口，保留现有插件的 Python 3.9 标准库核心。

首批动作控制在：公司/CIK 解析、列出公告、读取指定文件章节与附件、取得报表及 XBRL facts。输出原始获取包，由现有 fact-collector 转成 sources/claims，不让 MCP 的摘要直接变成研究结论。

获取包至少保留：工具/库版本、调用参数、获取时间、状态与截断标识；CIK、证券、form、accession、原文 URL、报告期与披露时间；原始数值、币种/单位/缩放、期间、concept、分部/合并范围；引文和原文定位。EdgarTools 是 SEC 材料的解析器，不能被计为第二个独立信息源。

它不会补齐股价、卖方一致预期、所有电话会逐字稿或后台定时调度。我们的研究框架负责比较解释、形成判断与更新结论。
