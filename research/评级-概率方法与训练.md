## 05 LEAP

**名称与链接、类别：** [LEAP](https://github.com/layingfish/LEAP)，证据冻结后的概率聚合方法及 Agent trace 适配器。[论文 v1](https://arxiv.org/html/2609.01337v1)。**代码 C / 方法 A / E2**。

**版本和实际阅读：** commit `3677fbb50242fcbeaafdfe258ba3b4767aeaf34e`。阅读 [normalizer 源码](https://github.com/layingfish/LEAP/blob/3677fbb50242fcbeaafdfe258ba3b4767aeaf34e/scripts/normalize_agent_trace.py)、[后端契约](https://github.com/layingfish/LEAP/blob/3677fbb50242fcbeaafdfe258ba3b4767aeaf34e/references/finalizer-contract.md)、[MIT 许可](https://github.com/layingfish/LEAP/blob/3677fbb50242fcbeaafdfe258ba3b4767aeaf34e/LICENSE)、完整 tree 与论文正文第4节、附录A—C、实验与限制。论文 PDF 也取回并解析；未执行仓库 SKILL。

**输入→处理→输出：** 完成的 JSON/JSONL/文本 trace＋问题、选项、冻结时点 → 提取字符串、排除操作日志/敏感片段、文本去重、构造 evidence、计算 SHA256 → snapshot JSON。论文后端则是冻结 evidence → 无证据先验＋逐条隔离的似然提取 → 同源聚类、可靠性抽样、温度/角色权重 → Gaussian 连续分布、单选 categorical 或多选 Bernoulli 边际＋留一证据贡献。

**可复用项：** `_stable_hash` 的规范 JSON 哈希；`_redact_sensitive`、输入解析与去重骨架；`evidence_bundle_hash`、`freeze_time` 和 `empty_evidence_bundle` 契约；direct/probability 两种结果必须共享证据哈希的公平比较方式。normalizer 仅依赖 argparse/hashlib/json/re/pathlib/typing，与标准库目标相合，但项目整体仍是 C。

**不可直接复用与缺失：** 后端契约第3行明确：`The public skill is an adapter. The probability model itself is supplied by a separate executable named by AGENTFUTURE_FINALIZER_BIN`。完整公开 tree 的唯一 Python 为 normalizer，未见先验构建、似然 elicitation、后验计算、dependency clustering、留一重算的实现。这是“该固定公开版本缺后端”，不能扩写为作者从未实现或后端永不公开。normalizer 的 `_binary_yes_no_signal` 用英文词汇重叠和否定正则猜标签；否定分支返回 opposes No，语义需要专项核验。`_literal_option_signal` 最多保留第一个命中选项，中文及复杂多选易失真。`freeze_time` 被写入哈希但没有逐证据发布时间的强制比较，不能把哈希当防穿越机制。question_family 对有选项统一 nominal_classification，也不能替代完整题型验证。

**依赖与许可：** 公开适配器 MIT。外部概率可执行文件、模型/API、论文实验数据的可分发许可未核实，MIT 不覆盖尚未取得的后端和第三方来源。模型调用成本由后端另定。

**效果证据与边界：** 原文在固定 evidence 上与 monolithic、同先验、近预算、线性 pooling 比较，报告多种模型/框架、多随机种子改善；Brier 并非所有模型都提高。读到 conditional independence 工作假设、同源 key 规范化、四个先验标准差排异常和局部抽样缩放。来源聚类不能消除全部相关性；重复模型回答的一致不等于证据真实；留一贡献是模型内敏感性，非因果贡献。GAIA/BrowseComp 信息查找题与金融未来事件存在任务差异，不能将总体改善当金融收益或实时校准保证。

**接入位置与理由：** 可作为研究结束→概率合成之前的冻结 snapshot 接口，以及报告中的证据敏感性附录。方法 A 因其直接补充可审计概率缺口；若做后端，应按论文明确重实现并单独评估，不应宣称已接入原版完整 LEAP。

**剩余核验：** 获得概率后端与版本、确认模型/数据权利、逐条审计似然映射/同源聚类、中文 trace 标签和时间拒绝规则、在同证据同预算的已裁决题集进行验证。

## 06 Consistency Checks for Language Model Forecasters

**名称与链接、类别：** [作者仓库](https://github.com/dpaleka/consistency-forecasting)、[论文 v1](https://arxiv.org/html/2412.18544v1)。概率逻辑一致性评价及修正。**代码 C / 方法 A / E2**。尝试 v3 HTML 返回404，随后成功取得 v1；结论限定已读版本。

**版本和实际阅读：** commit `08f0fdb0f347ede39e3fb7c18d60d204341a2517`。重点阅读 [Checker.py](https://github.com/dpaleka/consistency-forecasting/blob/08f0fdb0f347ede39e3fb7c18d60d204341a2517/src/static_checks/Checker.py) 中通用 max-min、Neg、And/Or/AndOr 和条件检查；[consistent_forecaster.py](https://github.com/dpaleka/consistency-forecasting/blob/08f0fdb0f347ede39e3fb7c18d60d204341a2517/src/forecasters/consistent_forecaster.py)；[proper_scoring.py](https://github.com/dpaleka/consistency-forecasting/blob/08f0fdb0f347ede39e3fb7c18d60d204341a2517/src/evaluation_utils/proper_scoring.py) 的接口及 [datatypes.py](https://github.com/dpaleka/consistency-forecasting/blob/08f0fdb0f347ede39e3fb7c18d60d204341a2517/src/common/datatypes.py)。阅读论文§2—5、Appendix F 的方法、修正结果和成本限制。

**输入→处理→输出：** 带裁决条件的二元问题 → 产生同义、否定、合取、条件等逻辑题组 → 独立询问预测器 → basic/frequentist/arbitrage violation；可选 sequential max-min 调整 → 修正概率和题组预测 metadata。NegChecker 的 basic 是 `abs(P+not_P-1)`；解析式用原P和`1-not_P`的加权 log-odds 平均，返回互补概率及 log-score 套利量。通用解使用 SciPy ODE/数值优化并把0/1裁至 epsilon。

**可复用项：** 概率关系约束清单、原始/修正值与题组 metadata 契约、无裁决时先报逻辑违例的评价思路。简单否定、互斥和蕴含残差可依据论文公式在标准库中独立实现；不能将该建议描述成已有源码获许可抽取。

**不可直接复用与原因：** 题组生成与模型工具深度耦合；NumPy/SciPy/Pydantic、jsonlines、dotenv、LLM wrapper 均超出标准库范围。源码默认 `verify_before_instantiation=False`，并可将非binary question_type直接改binary；不能照搬至数值/多选。生成失败后列表跳过与后续 zip(self.checks, cons_tuples) 的对齐风险应核验，不能把未运行的静态风险写成已复现故障。数值解包含开发者自己注明部分不可靠/破损的方法选择，需限定启用范围。另一个明确静态问题是 proper_scoring.py 的 `decompose_brier_score`：第110行在按 bin 汇总的循环中使用前一轮遗留的单个 `prob`，未使用该 bin 的预测均值；因此其 reliability 分解不应直接复用（未运行复现）。

**许可状态是评级约束：** 全树仅发现 [src/common/LICENSE](https://github.com/dpaleka/consistency-forecasting/blob/08f0fdb0f347ede39e3fb7c18d60d204341a2517/src/common/LICENSE)（MIT文字），没有根 LICENSE；GitHub API `license=null`。common 的许可明确，但不能自动外推覆盖兄弟 static_checks、forecasters 和 evaluation_utils。核心许可适用范围未确认，代码按标准 C；取得作者明确授权且完成适配后才考虑 B。模型/API、Metaculus/Manifold/NewsAPI 等数据分别受第三方条款约束，本轮未逐一核清。

**效果证据与边界：** 论文发现若干一致性指标与所测预测器 Brier 相关，条件关系较强，部分检查弱；分析排除比随机猜测 Brier 更差的预测器，因此相关性有选择范围。最关键的全文结论：ArbitrageForecaster 改善被优化检查的一致性，但未泛化至保留检查，也未改善真实预测效果。单组被投影为一致不代表整个预测器一致；所有题报50%可通过一些检查。递归题组调用成本按深度迅速增加。不能把逻辑审查当校准器或胜率提升器。

**接入位置与理由：** 放在概率报告发出前的只读质量审计层，显示冲突并触发回看证据/裁决口径，默认保留原概率，不静默覆盖。方法 A 因其直接覆盖逻辑缺口且原文提供反例与边界。

**剩余核验：** 作者确认许可范围；独立实现公式后测试边界、条件题语义和失效对齐；比较修正前后时间外 Brier，而非仅降低检查分数。

## 07 OpenForecaster / Forecasting-RL

**名称与链接、类别：** [仓库](https://github.com/OpenForecaster/scaling-forecasting-training)、[论文 v1](https://arxiv.org/html/2512.25070v1)，开放答案预测的合成数据、GRPO训练、检索和评价。**代码 B / 方法 B / E2**。

**版本和实际阅读：** commit `455e35d67e2b3e65f252cb148bdbe08ac9280706`。关键文件：[freeform reward](https://github.com/OpenForecaster/scaling-forecasting-training/blob/455e35d67e2b3e65f252cb148bdbe08ac9280706/libraries/verl/verl/utils/reward_score/freeform.py)、[binary reward](https://github.com/OpenForecaster/scaling-forecasting-training/blob/455e35d67e2b3e65f252cb148bdbe08ac9280706/libraries/verl/verl/utils/reward_score/binary.py)、[judge奖励](https://github.com/OpenForecaster/scaling-forecasting-training/blob/455e35d67e2b3e65f252cb148bdbe08ac9280706/libraries/verl/scripts/ours/genrm/brier_reward_function.py)、[retrieval.py](https://github.com/OpenForecaster/scaling-forecasting-training/blob/455e35d67e2b3e65f252cb148bdbe08ac9280706/embedding_retrieval/retrieval.py)、[leakage_filter.py](https://github.com/OpenForecaster/scaling-forecasting-training/blob/455e35d67e2b3e65f252cb148bdbe08ac9280706/qgen/filters/leakage_filter.py)，并取得 binary/freeform eval 与 utils，核查其解析/指标路径。读论文数据构造、奖励、检索、验证/测试和局限。

**输入→处理→输出：** 静态月度CCNews → 生成未来问题/裁决答案、LLM筛选/改写与答案字符串筛漏 → 时间过滤检索 → Qwen3/VeRL GRPO → `<answer>`和`<probability>`；开放答案经 judge 匹配，二元题另按 resolution 评分。

**可复用项：** 答案/置信度双字段契约；`filter_by_leakage` 的题干/background/criteria/answer_type答案串审计；`RetrievalEngine._is_document_valid` 遇缺日期拒绝、用`max_date < resolution_date-delta`过滤的骨架；binary Brier公式；free-form评价的“最佳答案+该答案置信度”语义。适合局部抽取或按公式重写，整体仍需明显适配。

**静态发现与缺失：** `freeform.compute_score`、`binary.compute_score`以及judge奖励使用 `if probability`，合法0被当缺失；部分路径允许[-0.1,1.1]，不能作为生产概率校验。多答案提取只warning总和偏差并覆盖同名答案。论文最终奖励是 accuracy + `S'=2p*correct-p²`；已读通用freeform及`brier_reward_function.py`路径为 `1+calculate_brier_score`，正确时为`2p-p²`，错误为`-p²`，即 S' 本身；不能据此声称这些文件就是最终accuracy+Brier训练入口。最终训练配置/奖励路由仍须逐一追踪。日期过滤相对裁决日，而本地应相对实际forecast_as_of，不能原样替代。字符串去漏抓不到语义暗示，也可能误删答案为短常用词的有效题。

**依赖与许可：** 根 [LICENSE](https://github.com/OpenForecaster/scaling-forecasting-training/blob/455e35d67e2b3e65f252cb148bdbe08ac9280706/LICENSE) MIT；vendored [VeRL LICENSE](https://github.com/OpenForecaster/scaling-forecasting-training/blob/455e35d67e2b3e65f252cb148bdbe08ac9280706/libraries/verl/LICENSE) Apache-2.0，应保留各自通知。训练依赖Torch、Transformers、Ray、Flash Attention、accelerate、datasets、Hydra等和GPU；检索依赖NumPy/tiny_knn/embedding，评估依赖模型和judge服务。读取 [OpenForecaster模型卡](https://huggingface.co/nikhilchandak/OpenForecaster-8B/blob/main/README.md) 与 [OpenForesight数据卡](https://huggingface.co/datasets/nikhilchandak/OpenForesight/blob/main/README.md)，均标MIT；这是卡片声明，基模Qwen3、judge和embedding上游许可及新闻原文权利未全部复核，不能据数据卡MIT授予新闻版权。卡片为读取时main，未固定HF revision，证据强度低于固定commit代码。

**效果证据与边界：** 论文用训练至2025年4月事件、May—Aug held-out与独立新闻来源，声明开发阶段只看validation，检索采用裁决前一个月的离线新闻；新闻源偏差、报道晚于真实发生及judge误差仍在。free-form S'越高越好，与传统binary Brier越低越好，不能混表排名。最优短答案的confidence不构成全事件空间完整分布，也不能直接换成资产上涨概率。训练效果不能由提示词单独继承。

**接入位置与理由：** 研究用评估侧车、离线题库构造和未来可选训练实验；模型仅作为可替换预测器，不成为当前标准库核心依赖。方法 B 因其相关但训练/GPU与开放答案判分前提明显超出当前插件。

**剩余核验：** 固定HF模型和数据revision；追踪最终accuracy+Brier启动配置；修正/测试0值与越界；时间外校准；judge一致性和新闻权利。

## 08 AutoCast

**名称与链接、类别：** [仓库](https://github.com/andyzoujm/autocast)、[论文 v2](https://arxiv.org/html/2206.15474v2)，事件预测数据集、检索训练基线和IntervalQA。**代码 B / 方法 B / E2**。

**版本和实际阅读：** commit `f7907d45dd3f5e58d70834f2d7770c404ef4baba`。读取 [model_multihead.py](https://github.com/andyzoujm/autocast/blob/f7907d45dd3f5e58d70834f2d7770c404ef4baba/autocast_experiments/src/model_multihead.py)、[train_fid_temporal.py](https://github.com/andyzoujm/autocast/blob/f7907d45dd3f5e58d70834f2d7770c404ef4baba/autocast_experiments/train_fid_temporal.py)、[forecasting_data_multihead.py](https://github.com/andyzoujm/autocast/blob/f7907d45dd3f5e58d70834f2d7770c404ef4baba/autocast_experiments/src/forecasting_data_multihead.py)，取得并检查检索脚本和 IntervalQA训练文件的结构；[README](https://github.com/andyzoujm/autocast/blob/f7907d45dd3f5e58d70834f2d7770c404ef4baba/README.md)、[LICENSE](https://github.com/andyzoujm/autocast/blob/f7907d45dd3f5e58d70834f2d7770c404ef4baba/LICENSE)。读论文§4和附录检索/校准。

**输入→处理→输出：** 带publish/close/answer/crowd时序的预测题＋按日新闻 → BM25检索与cross-encoder rerank → Static FiD T5（前十篇）或日度top1编码→GPT2时序模型 → 二元/多选预测、归一化数值。FiDT5包含sigmoid数值regressor、分类交叉熵和MSE；Temporal用mask对每日分类/数值损失聚合，按题型施加固定缩放。

**可复用项：** 问题和人群概率时间序列的数据schema；按日可用材料的回放设计；预测随离裁决时间变化的分层评估；数值任务与分类任务独立计量；有明确训练目标的时序更新基线。完整FiD/GPT2训练代码可供局部借鉴，因此B，不是README推断。

**不可直接复用与原因：** Torch/Transformers T5/GPT2、NumPy、GPU、BM25索引和sentence-transformer重排等依赖较重，代码有硬编码CUDA、旧模型forward接口和实验路径。数值sigmoid输出是归一化点估计，不能自动看作完整概率分布；IntervalQA区间评价是另一任务，不应以一个数值输出宣称区间已校准。带最终resolution和crowd的训练样本必须与预测时可见输入隔离。

**依赖与许可：** 自有代码根MIT；FiD源码保留Facebook版权头，第三方来源许可需保留和另核；IntervalQA 的 finetune_confidence.py 明确保留 HuggingFace Apache-2.0 文件头，不能统一写成全仓仅MIT。T5/GPT2及重排模型权重许可未逐一核实。README明确Metaculus只授权research purposes only，不能以代码MIT覆盖题目、群体时间序列或商用数据权利；CommonCrawl遵守其条款不等于取得每篇新闻版权。IntervalQA数据许可未核清。

**效果证据与边界：** 论文明确基线远低于人群；Temporal并非普遍优于Static，最大Static个体成绩更高。主文组合Score混合T/F、MCQ accuracy与数值L1，是任务指标，非Brier。附录报告时序模型校准误差改善，限定相应模型/题集/分箱，不是新LLM Agent效果保证。使用现代基模回放旧题时存在参数记忆污染，离线新闻本身不能解决。
