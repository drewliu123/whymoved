## 如何读这份清单

每项区分：解决的任务、输入输出和方法、公开交付物、效果证据、实际核验深度、尚不能认定的事情。作者的自报结果不等于独立复现；公开 README 里写有模块不等于已经读过其模块源码。

**核验标签：**
- **论文正文**：读取到论文主体，可指出方法或局限；不表示复现实验。
- **说明文档**：读取官方 README、作者介绍或技术文档；实现仍需源码检查。
- **局部代码**：读取具体代码/契约/目录；只对实际检查的部分作判断。
- **摘要**：只读取论文摘要及元数据，不能据此确认训练、评估和消融细节。
- **待补核验**：仅检索线索或主文未取到，不能据此给出确定结论。

所有项目均未在本地安装或运行，均未复现论文指标；没有检查完任何一个大型仓库的全部源码。代码许可、模型许可和数据许可必须分别核对；本轮不做统一商用许可判断。

## 对上一轮判断的更正

“最优先研究某几项”是根据任务贴合度给出的初步建议，不是基于统一数据、统一预算实测得出的排名。“没有一个可整套搬过来”应限定为“本轮尚未验证出这样的项目”，不能推广为开源生态不存在。对金融 Agent，只能说本轮材料未显示完整校准证据，不能断言项目没有概率能力。LEAP 缺外部概率后端是具体接口文本支持的事实；其他项目的完整程度不能照此类推。

# A. 事件概率预测

## 01. Metaculus / forecasting-tools

**链接：** https://github.com/Metaculus/forecasting-tools

**任务与输出：** 通用预测机器人开发框架；支持二元、多选、数值和日期题的结构化预测与报告。

**流程：** 读题 → 研究 → 多次独立预测 → 聚合 → 报告。TemplateBot 可覆写研究与预测函数；还提供 API、模型包装、重试与费用跟踪。

**公开交付物：** Python 库、模板机器人、示例、结构化数据类型和文档。

**效果证据：** 框架可用于构建参赛预测器；README 对自身机器人质量的描述不能替代同题比较。本轮没有核验一个能够代表整套框架的独立效果实验。

**实际核验：说明文档。** 已读取官方 README；没有运行 TemplateBot，也没有逐行确认所有默认聚合和校准实现。

**明确边界：** 可替换流程框架与最优概率算法是两件事。是否调用了校准器、用什么样本校准，必须落实到具体机器人和版本。

## 02. Halawi 等：Approaching Human-Level Forecasting with Language Models

**论文：** https://arxiv.org/abs/2402.18563
**作者代码：** https://github.com/dannyallover/llm_forecasting
**作者说明：** https://www.alignmentforum.org/posts/K2F9g2aQubd7kwEr3/approaching-human-level-forecasting-with-language-models-2

**任务与输出：** 在给定时点预测二元事件，输出发生概率。

**流程：** LLM 生成新闻查询 → 新闻 API 检索 → LLM 相关性筛选 → 针对问题摘要 → 基础/微调 GPT-4 多次推理和预测 → 截尾均值聚合。还研究了自监督样本筛选与微调。

**公开交付物：** 检索/预测代码、演示 notebook、清洗和原始数据入口。

**作者结果：** 作者说明中的测试集为 914 道题，每题最多五个检索时点；整体 Brier 为系统 0.179、群体 0.149，越低越好。特定选择条件下有局部领先，不是整体超越群体。

**实际核验：说明文档＋摘要。** 读取作者详细说明、作者仓库 README 和论文摘要；未逐表复核全文。

**明确边界：** 旧基模与新闻 API 的可用性需再测。历史日期检索不自动排除泄漏；不能把此研究的成绩当成我们换模型后仍会达到的成绩。

## 03. BLF 原论文：Agentic Forecasting using Sequential Bayesian Updating of Linguistic Beliefs

**论文：** https://arxiv.org/abs/2604.18576
**读取版本：** https://arxiv.org/html/2604.18576v1

**任务与输出：** 二元预测，维护概率与结构化信念状态。

**流程（正文复核后更正）：** 当前信念（概率、支持/反对材料、未决问题）→ 选择工具 → 更新信念 → 独立多次运行 → 默认概率算术均值聚合 → 层级 Platt 校准。论文另试验 logit 收缩，但其在 ForecastBench 上伤害所比较指标，不是最终默认。分来源偏移项用于处理不同题型的系统偏差。

**公开交付物：** 论文方法和实验；本轮没有确认作者官方完整预测代码仓库。第三方实现另列下一项。

**作者结果：** 在 400 个 ForecastBench 回放问题上报告强于所比较公开方法的成绩，有消融、配对比较和不确定性分析。论文明确承认回放排名未必迁移到实时预测，主要基模结论未必迁移到其他模型。

**实际核验：论文正文。** 已取回 v1 主体及附录，并核查校准和局限段落；未复现实验。

**明确边界：** leave-one-out 校准与严格按时间向前的部署校准不同；模型给出的“更新理由”仍需检验。不能用“贝叶斯”这个名称保证主观似然正确。

## 05. LEAP：Likelihood Elicitation and Aggregation for LLM-based Probabilistic Forecasting

**论文：** https://arxiv.org/abs/2609.01337
**介绍：** https://layingfish.github.io/LEAP/
**代码：** https://github.com/layingfish/LEAP

**任务与输出：** 在证据已收集的条件下生成预测分布，并审计证据贡献。

**论文/介绍方法：** 逐条解释证据 → 局部似然参数 → 显式先验 → 确定性概率聚合 → 留一条证据重算贡献。介绍称支持连续、单选、多选预测，并在固定证据比较中改善多项指标。

**公开交付物的实际情况：** 公开 tree 有 SKILL.md、finalizer-contract、normalize_agent_trace.py、论文 PDF 和网站等。接口明确写：The public skill is an adapter. The probability model itself is supplied by a separate executable named by AGENTFUTURE_FINALIZER_BIN。

**实际核验：官方说明＋摘要＋局部代码/契约。** 已读完整公开目录、SKILL、后端契约和 normalizer 的功能；HTML 论文正文抓取仅返回图片描述，不能声称读完论文。

**明确缺口：** 当前公开适配器要求另供概率后端。仅靠该仓库不能确认可运行论文中的完整聚合模型。也未实测作者效果；证据相关性和局部似然可靠性需要看全文及实现。

## 06. Consistency Checks for Language Model Forecasters

**论文：** https://arxiv.org/abs/2412.18544
**代码：** https://github.com/dpaleka/consistency-forecasting

**任务与输出：** 检查多个逻辑相关预测是否一致，输出违例/套利指标，并提供一致性修正预测器。

**流程：** 基础问题 → 同义、否定、合取、条件等问题组 → 分别预测 → 检查关系 → 可选一致性修正。

**公开交付物：** 题目生成、验证、检查、评估代码与数据；README 将 ConsistentForecaster 对应论文 ArbitrageForecaster。

**效果证据：** 摘要报告一致性指标与真实结果 Brier 相关。相关性不证明强制修正必然提高预测准确率；此前关于修正效果的细结论没有在本轮逐表全文核实。

**实际核验：说明文档＋摘要。** 已读仓库 README 和论文摘要，未运行检查器、未审计优化算法。

**明确边界：** 一致性检查可以抓逻辑冲突，但一个全部一致的预测器仍可能对世界判断错误。

**效果证据：** 能进行环境内策略比较；换市场、费用、风险约束后的泛化需要另验。

**实际核验：说明文档。** 未检查环境代码、奖励公式、训练稳定性和多随机种子实验。

**明确边界：** policy 给动作的概率是动作采样概率，不是市场会上涨的概率。

## 19. ForecastBench

## 20. FINSABER

# D. 评价理论、泄漏与研究问题选择

## 22. Temporal Leakage in Search-Engine Date-Filtered Web Retrieval: A Retrospective Forecasting Case Study

**论文：** https://aclanthology.org/2026.acl-short.65/

**研究任务：** 检查日期过滤检索能否可靠模拟过去信息集。

**作者结果：** 此实验中，至少一篇严重穿越文档的问题比例：Google 71%、DuckDuckGo 81%；直接透露答案 41%/55%。所测模型 Brier 在泄漏文档 0.10、干净文档 0.24。

**机制：** 网页事后更新、相关内容模块、错误元数据、缺席信息等。

**实际核验：官方摘要。** 已取回 ACL 页面和摘要；未复核完整抽样/标注过程，也未核实官方代码发布。

**边界：** 这些比例限定该研究，不能推广成所有检索的通用错误率。

## 23. Pitfalls in Evaluating Language Model Forecasters

**论文：** https://arxiv.org/abs/2506.00723

**研究任务：** 梳理 LLM 预测评估中的时间泄漏以及基准到真实使用的外推问题。

**公开交付物：** 论文方法批评和案例，不是新预测引擎。

**实际核验：摘要。** 没有逐案例核验全文。

**边界：** 支持要求更严谨评价，不能据此认定某个未检查的项目一定泄漏或无效。

## 24. Gneiting & Raftery：Strictly Proper Scoring Rules, Prediction, and Estimation

**论文：** https://doi.org/10.1198/016214506000001437
**作者公开 PDF：** https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf

**研究任务：** 概率预测的适当评分规则；连接预测分布、诚实报告与估计。

**对问题的具体作用：** Brier/log score 等用来评价概率质量；准确率只看跨没跨阈值，不能完整评价概率表达。

**实际核验：检索到作者 PDF 正文片段与出版信息。** 此轮未下载通读完整论文，不是新增预测算法或可运行 Agent。

**边界：** 评分规则不能替代数据质量和决策收益评价；不同问题和事件难度仍需公平比较。

## 25. On Calibration of Modern Neural Networks

**论文：** https://arxiv.org/abs/1706.04599

**研究任务：** 研究神经网络分类器置信度与实际正确率的匹配，比较后处理校准。

**作者结果：** 摘要报告多种分类架构的失校准，并发现温度缩放在许多数据集有效。

**实际核验：摘要。** 未核该方法在我们跨领域事件预测上的适用性。

**边界：** 图像/文档分类器实验不是 LLM 未来事件预测实验证明；有一个校准公式不意味着当前概率就已校准。

## 26. CruxBench: A Benchmark of Information Discovery

**论文：** https://arxiv.org/abs/2609.35879

**研究任务：** 评价模型提出的子问题是否能产生有价值的信息，使用 Value of Information 衡量对目标预测的帮助。

**作者结果：** 摘要称八个模型、293 个目标预测问题；信息发现仍具挑战，最强模型仅窄幅超过随机时点基线。

**公开交付物：** 本轮确认论文记录；未核官方完整代码和数据下载。

**实际核验：摘要。** 未验证信息价值计算、评分或实验细节。

**边界：** 有价值的补证据问题与已经正确的目标概率是两件事；它能启发研究路由，但不是现成概率后端。

# 最后：哪些结论现在能成立

1. 已有多条可供比较的路线，不应在未实测前只指定一个最优项目。
2. LEAP 公开接口依赖外部后端、BLF 第三方实现自承若干不复现部分，是具体材料直接支持的事实。
3. 部分工作确实输出概率，部分只输出估值、分数、方向或动作；必须按输出语义区分。
4. 所有作者实验都需要检查数据、版本、切分、成本、基线和污染；本轮核验深度不相同，不能统一称为已验证。
5. 选型仍需对候选实现做源码与可运行性检查，并在同一组问题、证据和预算下比较。本清单不代替这项实验。
