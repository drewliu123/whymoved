**实际读取的文件：** [data_pipeline.py](https://github.com/AI4Finance-Foundation/FinGPT/blob/ac5c5443fbeeafad801e7a3c188e4f24cfaad4d8/fingpt/FinGPT_Forecaster/data_pipeline.py) 全文；[utils.py](https://github.com/AI4Finance-Foundation/FinGPT/blob/ac5c5443fbeeafad801e7a3c188e4f24cfaad4d8/fingpt/FinGPT_Forecaster/utils.py) 全文；[prompt.py](https://github.com/AI4Finance-Foundation/FinGPT/blob/ac5c5443fbeeafad801e7a3c188e4f24cfaad4d8/fingpt/FinGPT_Forecaster/prompt.py#L103) 标签引导教师提示及日期过滤位置；[data.py](https://github.com/AI4Finance-Foundation/FinGPT/blob/ac5c5443fbeeafad801e7a3c188e4f24cfaad4d8/fingpt/FinGPT_Forecaster/data.py#L260) `gpt4_to_llama`/`create_dataset` 全文（260–364）；[requirements.txt](https://github.com/AI4Finance-Foundation/FinGPT/blob/ac5c5443fbeeafad801e7a3c188e4f24cfaad4d8/fingpt/FinGPT_Forecaster/requirements.txt)、[LICENSE](https://github.com/AI4Finance-Foundation/FinGPT/blob/ac5c5443fbeeafad801e7a3c188e4f24cfaad4d8/LICENSE) 全文。app/train_lora 已下载，仅搜索相关入口，不作为完整审查。

**输入→处理→输出：** 周价格/新闻/财务数据 → 按周组织信息、真实未来收益离散标签 → GPT-4 教师在已知标签条件下生成解释 → 去除学生输入中的标签、保留标签和教师解释训练 LoRA → 正面因素、风险因素、下周方向/幅度与分析文本。`parse_answer` 将 up/down 变为 ±1，将幅度区间近似成数值；没有返回事件概率。

**具体复用清单：** `parse_answer` 的结构化解析契约（应改为 JSON 并保留失败计数）；`calc_metrics` 的方向 accuracy、幅度 MSE 与文本 ROUGE 分离；`create_dataset` 按每标的原序列前段训练后段测试的结构；正反因素加可检验时间段的提示结构。适合局部改写，不建议完整导入训练栈。

**缺口与不可直接复用：** 教师被告知正确未来方向并要求支持性解释（prompt:103–107），生成理由不能当独立前瞻因果证据；学生标签移除只是数据加工，不能证明没有基模记忆污染。`utils.load_dataset` 在缺 test 时 fallback 为 shuffle 随机切分，与滚动预测不同。正则解析失败样本被 `calc_metrics` 跳过，若只报有效样本会有选择偏差。幅度解析对多位数字/开放区间较脆弱。没有在已读范围发现概率校准器、风险仓位、反思归因或组合风险模块；这只是已读 Forecaster 的范围结论。

**依赖与许可：** 根代码 MIT，需保留版权许可且无担保。依赖 torch、transformers、PEFT、bitsandbytes、accelerate、Gradio、yfinance、Finnhub；完整传递依赖许可未核实。代码明确支持 Llama-2/ChatGLM2 基模，基模与 LoRA 许可证未独立核验；Finnhub/Yahoo 新闻及行情、公开数据集各自授权未核实，不能套用代码 MIT。

**效果证据与边界：** 已读实现评价方向 accuracy、幅度 MSE、ROUGE；它们不衡量概率校准、扣费收益或实时稳健性。此轮未重读论文方法/实验正文、未核当前版本实验产物、未复现结果。作者 NLP/趋势成绩不能迁移成我们的事件概率效果。

**本地接入点：** 给 [fact-collector](../agents/fact-collector.md) 与 [研报模板](../skills/research/references/memo-template.md) 增加“支持/担忧/预测区间/证伪条件”的输出约定；结果进入 [journal.py](../scripts/journal.py) 的 hypotheses，另设方向标签，不能填入概率字段冒充 p。证据仍经 [check_claims.py](../scripts/check_claims.py) 检查来源和日期。

**评级理由与剩余核验：** 有具体数据转换/解析实现，局部可用故 B；训练与数据依赖重且与事件概率不匹配故非 A。方法对文本因素提炼部分相关故 B。后续需读点时财务选择函数、基模/数据许可、原始时间切分和解析失败率，做真正前瞻样本检验。

## 15. FinRL

**名称与类别：** [FinRL](https://github.com/AI4Finance-Foundation/FinRL)，强化学习交易环境与策略接口；论文 [2011.09607](https://arxiv.org/abs/2011.09607)。**代码 B / 方法 B / E2**。SHA：`7e98df461cbc7772f16a545a2f13b521e5d0b8f4`。

**实际读取的文件：** [env_stocktrading.py](https://github.com/AI4Finance-Foundation/FinRL/blob/7e98df461cbc7772f16a545a2f13b521e5d0b8f4/finrl/meta/env_stock_trading/env_stocktrading.py#L115) 买卖/现金成本与风险逻辑（115–220）、动作至奖励路径（309–386）；[env_stocktrading_stoploss.py](https://github.com/AI4Finance-Foundation/FinRL/blob/7e98df461cbc7772f16a545a2f13b521e5d0b8f4/finrl/meta/env_stock_trading/env_stocktrading_stoploss.py#L260) 奖励、动作、止损及现金不足处理（260–396）；[requirements.txt](https://github.com/AI4Finance-Foundation/FinRL/blob/7e98df461cbc7772f16a545a2f13b521e5d0b8f4/requirements.txt)、[LICENSE](https://github.com/AI4Finance-Foundation/FinRL/blob/7e98df461cbc7772f16a545a2f13b521e5d0b8f4/LICENSE) 全文。StableBaselines3 包装源码已保存但未通读，不对算法训练正确性评级。

**输入→处理→输出：** 行情特征、现金、持仓 → 外部策略动作按 hmax 缩放取整 → 先卖后买、按可用现金与持仓限量、扣费用、风险指标越阈值清仓 → 下一时点净值与按比例缩放的净值差奖励。不是事件预测；策略的动作概率也不是上涨概率。

**具体复用清单：** `_buy_stock` 的含费用预算上限；`_sell_stock` 的持仓约束；`step` 的期初/期末净值与费用/动作账本契约；turbulence 阈值覆盖策略动作的结构；历史成员 `member_col` 限制与退样本清仓的点时股票池意识。可抽出标准库版本的模拟账本与约束函数。

**缺口与不可直接复用：** gymnasium、NumPy/pandas、StableBaselines3/Ray 训练栈对插件过重。主环境以当前价格执行再转下一时点，特征是否在执行前可获得需独立验证；已读交易函数没有盘口深度、市场冲击、停牌和融资等完整模型。stoploss 环境与主环境动作单位不同；止损清仓在 `begin_cash >= stoploss_penalty * initial_amount` 条件内，不能把该变体当无条件硬止损。奖励含现金/止损/低利润惩罚，优化的不是单纯真实收益。没有概率校准与证据反思核心。

**依赖与许可：** 根 MIT。requirements 包含 gymnasium、StableBaselines3、Ray、ElegantRL、NumPy/pandas、TA-Lib、Alpaca/ccxt/JQ/WRDS 数据与交易接口；此轮未逐个核第三方及传递许可。训练策略权重未核实；行情数据与供应商条款未核实，根 MIT 不授权外部数据。没有运行任何接口。

**效果证据与边界：** 已读源能确认仿真成本/约束存在，不能确认某篇实验用了合理费用、正确收盘执行或无幸存者偏差。原论文和跨市场多种子结果未本轮复核；净值奖励不提供概率校准证据。

**本地接入点：** 为 [journal.py](../scripts/journal.py) 旁的研究模拟产物设计 cash/position/fee/mark/reward 字段，在 [plan.json 示例](../journal/M20261030-01/plan.json) 所在计划归档流程旁提出离线执行假设；仅作为未来适配建议，本轮未新增或改生产脚本。

**评级理由与剩余核验：** 现金、费用和动作模块真实存在可局部借用，整体依赖与任务适配明显故 B；仿真约束方法对决策参考局部相关故 B。后续应逐变体检查单位、交易时间、成本和缺失价格，读策略 wrapper/原论文完整实验并核数据授权。

**输入→处理→输出：** 新闻/财报与角色 query → 短中长及反思记忆检索（相似度＋新近性＋重要性）→ LLM 决策/引用记忆 ID → buy/sell/hold 变成持仓增量 → 滚动盈亏反馈更新曾引用记忆的重要性并衰减。Train 接受未来价差、动作按价差符号确定；Test 在 `step` 显式将 cur_record 置 None，并用模型决策，二者必须分开解释。

**具体复用清单：** `LinearCompoundScore`、`ExponentialDecay` 可改为标准库 math；每条记忆的 text/id/date/importance/recency/access_counter 字段；反思返回引用记忆 ID 的契约；按 train/test 分开的输入契约及解析失败 hold 的保守分支。将检索和结果反馈写成可审计记录，比直接复制 Agent 更适合本地。

**缺口与不可直接复用：** `MemoryDB.query(query_text, top_k, symbol)` 没有 as_of 参数或日期过滤；安全性依赖按序入库和 checkpoint 边界。候选先取 top_k 再去重，可能不足 k；加入向量时归一化、查询向量路径未见同样显式归一化，组合分数尺度需验证。portfolio 的反馈是窗口持仓盈亏符号，统一奖励当时检索记忆，不证明每条材料真实贡献。持仓每次 ±1 累加，已读 Portfolio 没有现金、费用、仓位上限或完整风险预算。训练用未来结果可以做历史经验教学，训练记忆若穿越测试截止则会污染；本轮未证明其全流程存在或不存在此污染。

**依赖与许可：** 根 MIT；Python 限 3.10，依赖 FAISS、Guardrails、NumPy、Polars、LangChain、Torch/Transformers、sortedcontainers。第三方依赖许可未完整核验。模型/embedding 服务与权重许可未核实；财报、新闻和价格来源再分发授权未核实。

**效果证据与边界：** 论文收益领先与认知跨度调参仍是既有清单所述作者摘要结论，本轮未核原表、选择集、成本、多次调用随机性或独立复现。记忆重要性是检索启发式，不是证据可靠概率或模型校准。

**本地接入点：** 给 [journal.py](../scripts/journal.py) 已裁决假设生成经验条目，引用 memo_id/hyp_id/claim_id 和 available_at；由 [red-team](../agents/red-team.md) 检索同类失败经验。反馈以裁决后的假设为单位，不把交易赚钱直接当论据正确；原始 [claims 账本](../journal/M20261030-01/claims.json) 继续保留来源。

**评级理由与剩余核验：** 存在可用记忆模块，局部 B；重依赖、日期隔离与结果归因需重做，方法 B。剩余需读所有 checkpoint/层间迁移路径，核 train/test 日期和未来标签可用时间，增加仅历史可读的数据契约，再评价检索收益。

**输入→处理→输出：** 行情/新闻/图与历史记忆 → 低层市场变化反思（reasoning/query）→ 高层历史动作与理由复盘（reasoning/improvement/summary/query）→ 决策 action/reasoning → 环境执行和 JSON/HTML 归档。action 是离散买卖持有，已读决策契约不输出事件概率。
